## 发现的问题与通用修改

1. 选型阶段重新加载整包驱动API：工具适配器限制usage必须带具体references，默认只提供selection视图。对所有器件适用，未修改器件驱动或硬件数据。
2. 无依据的闲置端口接线建议：系统Prompt明确选型只报告有来源的接口需求，不提供未查证的端口连接处理。提示词不能保证所有自然语言判断正确，仍需后续验证。
3. 主Agent委派时自行引入候选、驱动及接线细节：主Prompt要求忠实转达用户范围，把查库选型留给子Agent。
4. 来源校验过窄：认可实际返回的provenance、platform配置和included原文；仅出现在documents目录但未读取的文档仍不能作为已读来源。
5. 提交校验失败原本只能停止：改用LangChain结构化输出校验，将具体原因送回子Agent，最多一次修正；两次拒绝停止，保留计费响应和错误证据。
6. 用量统计：主子共享任务账本，UI本轮合计包含子Agent；复用协调器时刷新本轮事件接收器，避免计入上一轮。详细日志ID不能伪装成阶段交接ID。
