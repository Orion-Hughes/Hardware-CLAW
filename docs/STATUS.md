# 当前支持范围与下一步

本页只说明当前实现，不替代运行报告或功能验收。

## 公开包检查

从仅包含Git暂存内容、不含本机密钥、生成工程或工具安装的源码副本运行：299项离线软件回归通过，独立C++绘图库测试通过。检查使用现有Python依赖环境，不等于在全新电脑完成所有依赖安装。552份上游文件哈希和自有文档相对链接已核对；真实模型、仿真和实物测试仍需分别授权与验收。

## 已实现

- LangChain主协调Agent和选型、生成、验证规划三个固定子Agent。
- Chainlit网页、聊天历史、任务/工程绑定、同工程多轮修改。
- 本地硬件连接卡、上游Wokwi/驱动资料、来源版本及哈希校验。
- 接线和固件生成、不可变修订、程序派生GPIO表。
- 候选工程的宿主静态检查、真实PlatformIO编译、诊断反馈和有限修复、VS Code仿真目录导出。
- Agent3测试计划生成和总体审查；已有受控Wokwi CLI/MCP适配，但执行闭环尚未接通。
- 独立网页烧录：受管工程选择、端口枚举、N32R16V固件准备、镜像预览、人工二次确认、日志和取消。
- 轻量绘图库及独立C++测试，不把示例游戏或某个工程当作通用生产模板。

## 明确限制

- 主要支持Windows / PowerShell、Python 3.12和登记的ESP32-S3基线，尚非通用多板卡发布。
- 硬件库存在不等于器件都已验收；摄像头、咪头、扬声器及实物屏参数等仍有缺口。
- Agent3目前只规划，不自动仿真、判定功能或进行仿真驱动修复。
- 实物构建按采购记录N32R16V配置，尚未核对丝印、验证启动、PSRAM或实际上传。
- 仿真ST7789为240×240，不能自动当成实物240×320屏；显示效果和完整画面初始化仍待完善。
- 模型调用计费，当前开发预算较宽。修改上限前查看`hardware_claw/limits.py`，对真实测试单独授权，不启动无限任务。
- 网页仅用于本机，不作为公网多用户服务部署；不要把服务端口暴露到互联网。

## 下一步

1. 核对实物板卡与外设，用户确认后完成首次烧录和串口验收。
2. Agent3接入真实仿真执行、证据保存、规则判定和有界纠正。
3. 按[入库流程](guides/HARDWARE_ONBOARDING.md)扩展硬件与板卡，分别验证依赖安装、编译、仿真和实物。
4. 改善生成稳定性、显示效果以及模型成本；统计时间与提供方token，保留原始失败证据。

代码回归和编译不能外推为功能验收。历史研究、实验和付费运行证据在维护者本机保留，不包含在公开运行包中。
