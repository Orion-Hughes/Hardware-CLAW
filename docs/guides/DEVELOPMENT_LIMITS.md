# 测试阶段运行预算

统一配置：`LangChain/hardware_claw/limits.py`，配置版本 `development_v2`。修改后重启服务；这些是上限，不是每次运行需要用满的目标。所有工程使用同一套规则。

| 项目 | 主协调每轮 | 生成阶段 |
| --- | --- | --- |
| 单次模型输出 | 4096 tokens | 16384 tokens |
| 模型调用 | 24 | 32 |
| 工具调用 | 64 | 64 |
| 图步数兜底 | 208 | 272 |
| 总时限 | 900 秒 | 600 秒 |

- 单次 API 请求120秒，不自动重试；保留最近6轮完整问答，输入最多32000字符。
- 单次编译900秒。仿真适配器预留每轮最多10次、每次30秒模拟时间、180秒宿主墙钟、4MiB日志；这些执行接口当前未注册，不是自动运行授权。
- 烧录接口仅由用户显式调用：准备不连接硬件；确认计划有效15分钟，实际执行最多180秒，失败/取消不自动重试。当前未实物验证，详见 [烧录指南](FLASHING.md)。
- 工程最多128文件，单文件256KiB，总计2MiB；设计最多64元件、256连线、64依赖；补丁最多128000字符。
- 每任务累计上限 2,000,000 已报告 tokens，主 Agent 和三个子阶段共享，恢复不重置。已有任务按当前上限减去已记录的用量计算余额。其他阶段限制以`LangChain/hardware_claw/limits.py`为准。
- 生成阶段对可定位的检查或编译诊断最多做两次普通修正。达到预算后的有限收尾与程序接管见[当前架构](../architecture/OVERVIEW.md)及`generation_finish.py`。
- 普通修正每批初始上下文最多 64,000 字节、含续读与反馈最多 112,000 字节，最多 3 次模型请求，每次输出最多 8,192 tokens。可以续读登记的应用源码或只读本地库 API；最后一次只能提交修改。补丁语法和匹配问题一次性反馈，校验通过后才写入。预算外的单次收尾仍为 12,000 字节输入、2,048 tokens 输出，不增加重试。
- 图步数随模型调用上限计算，一个模型与工具回合会消耗多个图步。若模型、工具或图步数到限且本轮已经写齐当前候选，程序仍会检查、编译及按结果导出；不会增加本阶段的模型修正请求。

主协调任务与运行记录位于 `workspace/.tasks/coordinator.sqlite3`，旧工程的原始记录仍保存在 `.hwclaw/runs/`。用量以提供方返回为准；缺失用量时明确标记不完整。

后续按多种任务的成功、失败、截断、耗时及成本分布调整，不能只为某个例子放宽或收紧。生成阶段无效业务工具 JSON 会带解析位置反馈，最多允许两次重交，格式错误调用不写入文件。报告格式另有一次修正额度。仿真日志不等于功能验收通过。

官方MCP适配器共用预留仿真次数预算：单次会话180秒，单请求45秒，最多64个动作（含等待）、显式等待合计60秒。这是本地封装限制，不是Wokwi官方上限。规划器每场景最多32个事件、转换后最多64操作；上限不是数量目标。原始JSON累计16MiB，单证据文件16MiB；截图与官方串口缓冲区本身可能不完整。当前未接入Agent3执行，源码和测试分别见`LangChain/hardware_claw/adapters/wokwi_mcp.py`与`tests/test_wokwi_mcp.py`。
