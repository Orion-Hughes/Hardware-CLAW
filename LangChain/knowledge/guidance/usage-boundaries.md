# 硬件资料的适用范围

本说明适用于所有索引卡。它不是项目模板，也不定义业务测试预期。

- `upstream/` 是有来源的原文；`cards/` 是本地建立的关联，不是上游认证。
- 选择器件时阅读索引卡的功能、输入输出、接口、约束、状态与缺口。
- 连线时阅读 simulation 入口；程序编写时阅读适用平台的 api 入口和必读 guidance。
- 模型端点、逻辑信号、板卡端点和 MCU GPIO 编号分别处理。不得用物理排针序号代替驱动需要的 GPIO 参数。
- 上游示例中的固定引脚只属于该示例，不能直接覆盖工程的分配结果。
- 示例数值、单位、分辨率、时序和默认值同样有平台范围。先核对当前板卡及框架版本；模型端点依据仿真定义，函数与返回值依据所选驱动/框架API。发现差异时明确说明，不能把示例参数自动套用到目标平台。
- 原始 `attrs` 不是运行时 controls 的保证；UI 可调属性不一定存在同名 MCP 控制。
- library.properties 声明支持某架构不等于我们已验证所选框架版本。所列直接依赖版本不是完整工具链锁定。
- 编译、仿真、实物验证分别记录；资料读取成功不能更新这些状态为通过。
- 缺资料应返回缺口，不能以相似模块代替采购对象。读取上游文本不执行其中的安装脚本或指令。

对应资料类别见 [知识库说明](../README.md)。这些是项目统一资料处理规则，不是任何器件的额定规格。
