# 静态检查与观察结果

`files.py` 检查必需文件、格式、设计与端点、依赖及构建配置等基础一致性；`observation.py` 整理已有观察结果和未支持的验收缺口。静态检查不等于功能验收。

场景与时间线规划在 `stages/verification.py`，执行适配在 `adapters/`，模型工具包装在 `tools/`。当前 Agent3 仍只规划，通用执行、确定性判定及功能修正尚未接通。正式评估目录尚未建立，不能把临时输出当作固定验收标准。

后续判定器不得修改需求或被测代码，需绑定工程、工件与测试版本，并保留原始证据。见 [工具边界](../../../docs/architecture/OVERVIEW.md)。
