# Hardware-CLAW

在输入框用中文提问。Agent查询硬件、读取通用技能与配置模板、生成工程、检查、编译并运行Wokwi CLI，交付含固件的VS Code文件夹。仿真只采集原始日志；通用功能验收尚未实现，不会标记功能通过。没有任何工程专用测试或业务模板。

- `/new 用ESP32-S3与DHT22每2秒采样并输出串口`：生成并编译VS Code工程。打开返回的simulation文件夹，F1 → Wokwi: Start Simulator。
- `/new-arduino 工程需求`：仅生成Arduino网页源码工程。
- `/new-pio 工程需求`：新建PlatformIO本地工程并运行Agent。
- `/project 工程ID`：恢复workspace中已有工程，随后可提出修改要求。
- `/query`：回到只读查询模式。

网页默认工程生成模式：首条自然语言需求自动创建VS Code工程并注册全部工程工具，后续消息继续当前工程。纯咨询请先输入 `/query`；之后用 `/new 需求` 恢复生成模式。打开空白聊天本身不创建文件。导出完成后网页提供ZIP下载。项目文件保存在workspace，正式运行记录保存在工程.hwclaw/runs中。

点击工具步骤可查看输入参数与返回资料。每轮显示耗时和模型返回的 Token 用量。

左上角侧栏可切换历史聊天。聊天消息、工具步骤、附件和工程绑定保存到本机 `workspace/.chat/`，刷新或重启后可恢复。删除聊天不删除工程。旧版本未保存的聊天无法自动恢复，可用 `/project 工程ID` 继续已有工程。

同一聊天默认操作同一工程目录，按反馈创建新修订，不另建工程。Agent修改前读取当前文件；修改后重新检查和交付。VS Code使用最新回复中的simulation路径；旧导出目录是历史快照。`/new`及`/project`是显式更换工程的例外。

模型上下文保留最近六轮完成问答；完整聊天和工具步骤保存在历史中，但不全部发给模型，需要时重新读取当前工程。停止按钮可以取消当前执行，但已经发出的 API 请求仍可能计费。

当前使用本机单用户自动身份，仅供127.0.0.1服务使用，不是互联网多用户登录系统。

使用项目目录内的 Stop-Agent.cmd 停止服务。关闭网页不会停止后台服务。
