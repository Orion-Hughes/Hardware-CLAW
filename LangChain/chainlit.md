# Hardware-CLAW

在输入框用中文提问。Agent查询硬件、读取通用技能与配置模板、生成工程、检查、编译并交付含固件的VS Code文件夹。当前不会自动运行Wokwi CLI/MCP；请打开返回的simulation文件夹，手动执行“Wokwi: Start Simulator”。通用功能验收尚未实现，不会标记功能通过，也没有任何工程专用测试或业务模板。

- `/new 工程需求`：开始新的协调任务。
- `/project 工程ID`：绑定 workspace 中已有工程，随后可提出修改要求。
- 顶部“固件烧录”：进入独立页面，选择 workspace 工程文件夹、串口和目标配置，编译/准备镜像、查看预览、人工二次确认后烧录。操作不调用模型；打开页面和准备预览不会写入硬件，实际烧录尚待实物验证。
- `/ports`、`/flash-plan`：保留只读快捷命令；完整烧录不再需要使用命令行。

直接输入需求即可进入主协调流程。主 Agent 根据请求委派选型、生成或验证规划；只有进入生成阶段时才按需创建工程。后续消息继续当前任务及已绑定的工程。导出完成后网页提供 ZIP 下载。工程和任务记录保存在 workspace。

点击工具步骤可查看输入参数与返回资料。每轮显示耗时和模型返回的 Token 用量。

左上角侧栏可切换历史聊天。聊天消息、工具步骤、附件和工程绑定保存到本机 `workspace/.chat/`，刷新或重启后可恢复。删除聊天不删除工程。旧版本未保存的聊天无法自动恢复，可用 `/project 工程ID` 继续已有工程。

同一聊天默认操作同一工程目录，按反馈创建新修订，不另建工程。Agent修改前读取当前文件；修改后重新检查和交付。VS Code使用最新回复中的simulation路径；旧导出目录是历史快照。`/new`及`/project`是显式更换工程的例外。

模型上下文保留最近六轮完成问答；完整聊天和工具步骤保存在历史中，但不全部发给模型，需要时重新读取当前工程。停止按钮可以取消当前执行，但已经发出的 API 请求仍可能计费。

当前使用本机单用户自动身份，仅供127.0.0.1服务使用，不是互联网多用户登录系统。

使用项目目录内的 Stop-Agent.cmd 停止服务。关闭网页不会停止后台服务。
