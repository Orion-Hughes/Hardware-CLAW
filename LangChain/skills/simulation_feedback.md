# 仿真观察与反馈

所有工程使用同一流程：check_project_files→compile_project→simulate_project→evaluate_tests→export_project。

simulate_project在受控时限内运行当前固件和电路，采集真实串口与CLI日志；不按元件类型选择特殊用例，不要求固定业务输出。evaluate_tests核验证据绑定并报告执行状态。当前没有通用需求验收实现，正常观察返回unsupported，功能状态为未验证，不可声称测试通过。

日志用于提出诊断假设，不能仅凭出现或缺少某个词断言业务正确。用户需求与器件资料指导实现；不得添加只适用于某个工程的技能、业务模板、测试预期、解析规则或修复补丁来掩盖问题。

失败先读取当前源码与设计，对照原始日志和器件资料。修改必须说明与问题证据的关系；禁止伪造输出、修改验收标准、仅整理格式后反复重试。工具故障不归因于固件。缺少验收能力应报告缺口并交付供人工检查，不能针对当前项目临时定制通过规则。

每轮最多3次仿真，单次模拟25秒、墙钟90秒，总任务900秒。达到模拟观察窗口不等于业务失败，墙钟超时和进程错误单独报告。同一固件/电路可复用证据；无进展停止。修改后检查、编译并重新采集。宿主兜底打包不编辑源码、不改变未验证状态。
