# 在线模块资料核查

日期：2026-10-24。方法：直接读取厂家网页正文。搜索接口本轮返回404，因此改用厂家站点。以下为阅读摘要，不是网页完整快照，未运行网页中的命令。

## DHT22：Waveshare参考模块

来源：https://www.waveshare.com/wiki/DHT22_Temperature-Humidity_Sensor

- 厂家明确标注DHT22/AM2302，供电3.3–5.5V。
- 厂家接头编号：1 VCC、2 GND、3 DOUT。需结合原图定位1脚，不假设观察方向。
- 页面提供单线通信说明、接线和例程入口。
- 正文时序部分存在µs与ms混用的疑似笔误，因此不据其叙述重写底层时序；采用成熟驱动，并在需要实现协议时再交叉核对数据手册。
- 仅确认为有文档的参考模块，不确认为采购红板同款。

## TFT：Waveshare 2inch LCD Module

来源：https://www.waveshare.com/wiki/2inch_LCD_Module

- 厂家型号为2inch LCD Module，控制器ST7789V、240×320、SPI。
- 列出VCC/GND/DIN/CLK/CS/DC/RST/BL的逻辑连接；此列表不是我们采购蓝板的物理针序。
- 文档支持3.3V/5V，但要求供电和逻辑电压匹配；该条件不可遗漏，也不能推广到所有ST7789模块。
- 提供Arduino、STM32、Raspberry Pi连接表和例程。对应MCU GPIO号码不能直接照搬到ESP32-S3。
- Raspberry Pi表有DS标记，与其他表和协议说明中的DC不一致；将其作为文档差异保留，不新增一个DS信号。
- 仅作为具体参考型号，不冒充采购的无明确板号蓝板。

## 资料库策略

优先选择可追溯的厂家具体型号；分别记录文档支持、编译通过、仿真通过、真机验证。没有购买不等于不支持，没有真机测试也不等于不能形成文档级方案。只有关键参数冲突或无法确定型号时才询问用户，照片不作为默认输入。
