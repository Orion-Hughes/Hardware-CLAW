# 硬件配置记录

本文件只提供连接卡所引用的配置出处，不包含个人采购、报销、联系方式或学校信息。`owned_hardware`指维护者登记的原型硬件，不表示克隆本仓库的用户也拥有这些器件。

| 硬件 | 登记规格 | 边界 |
|---|---|---|
| 主控 | ESP32-S3-DevKitC-1 / N32R16V，32MB Flash、16MB PSRAM | 来自原型配置记录，尚未核对实物丝印；网页实物构建与Wokwi基线分开 |
| 屏幕 | ST7789，2英寸，240×320，8针SPI模块 | 不能直接等同240×240仿真模型；物理引脚、电源和偏移待核对 |
| 温湿度 | DHT22/AM2302红板模块 | 模块针序、上拉与供电须按实物确认 |
| 灯环 | WS2812，5V，8灯 | 固件数量与diagram实例属性须一致；电源及信号电平另行确认 |
| 舵机 | SG90，180度 | 库/平台兼容、供电、电流和实际行程需独立验证 |
| 摇杆 | PS2双轴加按键模块 | 对应两路ADC和按键，针序与供电按模块确认 |
| 摄像头 | USB摄像头与转接线 | 型号、UVC格式和接口电路未确定，非已支持的通用摄像头 |
| 麦克风 | 驻极体咪头 | 不是I2S数字麦克风，偏置/放大/采样电路存在缺口 |
| 扬声器 | 8Ω / 1W | 需要合适功放，不能直接当作GPIO负载 |

参考器件和仿真变体由连接卡的`record_role`、`inventory`和`simulation`分别标明。SSD1306、MPU6050、DS1307、HC-SR04、电位器、按钮、BMP180等参考配置不等于维护者实物采购清单。

Wokwi中的连线有效、软件编译通过、仿真观察通过、实物功能通过是不同层级，不能互相替代。来源见[索引](SOURCES.md)，具体参数以`LangChain/knowledge/cards/`及其锁定文档为准。
